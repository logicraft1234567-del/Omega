Five layers of protection on every order.

From the moment the item is packed to the moment a dispute is settled, each step leaves evidence that can be checked.

{{ icon('lock-keyhole') }} Feature 01

Package Lock Verification

Every transaction gets a unique package identity.

  • {{ icon('circle-check-big') }}The seller films the item going into the package
  • {{ icon('circle-check-big') }}The package is closed on camera
  • {{ icon('circle-check-big') }}A unique tamper-evident seal is attached and its ID recorded
{{ icon('truck') }} Feature 02

Courier Chain of Custody

Every handover is logged, so nobody has to guess where the parcel was.

  • {{ icon('circle-check-big') }}Handovers, scans, timestamps and tracking events
  • {{ icon('circle-check-big') }}Seal condition recorded at each stage
  • {{ icon('circle-check-big') }}Courier APIs integrated where available
{{ icon('fingerprint') }} Feature 03

Advanced Product Fingerprinting

The device is identified by what it is, not what the listing says.

  • {{ icon('circle-check-big') }}Serial number, IMEI and accessories captured
  • {{ icon('circle-check-big') }}Unique physical marks and condition recorded
  • {{ icon('circle-check-big') }}Compared again at every verification stage
{{ icon('video') }} Feature 04

Video Authenticity Analysis

Footage is checked for signs it was cut, reused or reworked.

  • {{ icon('circle-check-big') }}Suspicious edits, repeated footage, missing intervals
  • {{ icon('circle-check-big') }}Inconsistent metadata and possible manipulation

These are risk signals, not proof of fraud. A person makes the call.

{{ icon('user-check') }} Feature 05

Independent Dispute Resolution

One evidence timeline shows what the buyer, seller and courier each recorded.

  • {{ icon('circle-check-big') }}Side-by-side timeline of all three records
  • {{ icon('circle-check-big') }}Human reviewers make the final, fair decision
